# Welcome to Diamond

This is a small vault for trying things out. Everything in it is a plain
file, so change whatever you like.

Press **Cmd-Shift-P** (Ctrl-Shift-P on Linux) to see every command.

## Start here

- [[Launch]] is a project note. Run "Show this note as a board" on it.
- [[Overview]] holds a query. Switch to the reading view with Cmd-E to see
  the table it computes.
- [[Budget]] has a table and some properties.
- [[Ideas]] is a loose note that links around.
- `Map.canvas.toml` in the sidebar is a canvas.
